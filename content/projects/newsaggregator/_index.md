## Om projektet
Jeg lavede dette projekt med tankerne om at det kunne være sjovt at arbejde med mange forskellige artikkel api's 
og bruge AI til at bearbejde artikler ind til nogle 'korte' opsummeringer.


## Teknologier
- JAVA 25
- PostgresSQL 16
- Maven 
- Javalin 7
- JPA/Hibernate 7
- Jackson
- Lombok
- JWT (TokenSecurity)
- jBCrypt
- Google Gemini API
- The Guardian Open Platform API
- JUnit 5, Testcontainers and Hamcrest
- Rest Assured
- Docker
- GitHub Actions
- Docker Hub, Watchtower and Caddy on a DigitalOcean droplet.
